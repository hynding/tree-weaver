# @tree-weaver/formats

Import and export Tree Weaver forests and trees as JSON, YAML, XML, HTML and Markdown.

Part of [Tree Weaver](https://github.com/hynding/tree-weaver). Most projects install
[`tree-weaver`](https://www.npmjs.com/package/tree-weaver), which includes this package, the
other libraries and the `tree-weaver` CLI.

```sh
npm i @tree-weaver/formats
```

See [AGENTS.md](https://github.com/hynding/tree-weaver/blob/main/AGENTS.md#using-the-packages) for
the main entry points and the [format guide](https://github.com/hynding/tree-weaver/blob/main/docs/format.md)
for the data model.
